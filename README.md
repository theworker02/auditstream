# auditstream

Audit encode/decode helpers for stream payloads in pipelines.

**Site:** https://theworker02.github.io/auditstream/

## Install / run

```bash
git clone https://github.com/theworker02/auditstream.git
cd auditstream
node src/cli.js
node --test
```
